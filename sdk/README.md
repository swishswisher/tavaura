# Tavaura SDK (demo)

Early, local-only embed demo for the Tavaura widget.

## Quickstart

1. cd sdk
2. npm install
3. npm run build
4. Open demo/index.html with a static file server (e.g. VS Code Live Server or `npx serve .`)

Then open the URL in your browser and use the "Try on with Tavaura" button.
