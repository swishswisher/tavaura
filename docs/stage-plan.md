# Tavaura Build Stages

This file is retained as a short index. The authoritative execution detail is
in [IMPLEMENTATION_ROADMAP.md](IMPLEMENTATION_ROADMAP.md).

1. **Phase 0 — Decision and state lock:** completed when the canonical project
   documents and accepted architecture decision records are committed.
2. **Phase 1 — Repository and security stabilization:** repair Git ownership,
   patch dependencies, close privileged routes, secure media fetching and
   harden tenant isolation.
3. **Phase 2 — Known-good canonical garment:** finish and validate the canonical
   T-shirt in Marvelous Designer and across selected SMPL-X bodies and poses.
4. **Phase 3 — SMPL-X runtime bridge:** replace the mock runtime engine with a
   structured SMPL-X/canonical-garment render provider.
5. **Phase 4 — 2.5D near-realism:** add materials, lighting, occlusion, identity
   approximation, progressive enhancement and short motion output.
6. **Phase 5 — Production garment ingestion:** implement safe intake, real
   segmentation/classification, archetype deformation, immutable manifests,
   QC and review.
7. **Phase 6 — Product integration:** unify the SDK and connect storefront,
   admin, jobs, signed assets, usage and privacy flows end to end.
8. **Phase 7 — Launch hardening:** tests, observability, deployment, recovery,
   performance, commercial licences and pilot launch gates.

Cosmetics, social challenges, broad commerce connectors and additional garment
families remain post-core extensions unless required by an identified pilot.
