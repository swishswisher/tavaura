# Tavaura Build Stages

1. **Stage A: Project setup & scaffolding** – Establish repo structure, tooling, CI, secrets management, and shared contracts.
2. **Stage B: Backend core services** – Implement auth, catalog ingestion, session orchestration, storage integrations, and admin APIs.
3. **Stage C: Frontend marketing site** – Build the marketing site, product pages, waitlist form, and brand storytelling blocks.
4. **Stage D: SDK and viewer widget** – Ship the embeddable loader, viewer iframe/web component, and the JavaScript SDK API surface.
5. **Stage E: Apparel try-on core (3D + photo)** – Deliver garment ingestion, 2D→3D assets, photo try-on pipeline, and fit adjustments.
6. **Stage F: Cosmetics (lipstick)** – Add lip segmentation, shade catalog, realistic lipstick rendering, and cosmetics UI flows.
7. **Stage G: Avatar customization & avatar-from-photo** – Enable avatar generation from photos, hairstyle/skin tone customization, and sizing profiles.
8. **Stage H: Accounts & profiles** – Introduce user accounts, saved looks, organization management, and role-based access.
9. **Stage I: Social challenges & sharing** – Launch challenge templates, shareable links, social metadata, and engagement analytics.
10. **Stage J: Integrations** – Provide the universal snippet plus packaged integrations for Shopify, WooCommerce, and guides for Wix, Squarespace, GoDaddy, etc.
11. **Stage K: Testing, QA, and deployment** – Harden automated tests, staged deployments, performance validation, and launch readiness.
